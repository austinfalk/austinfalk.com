# AGENTS.md

Austin Falk's personal site (austinfalk.com): a static Astro site deployed to
Cloudflare Workers static assets. It replaces a WordPress site and must keep
that site's search ranking. Two pages: `/` and the biography at `/about`.

## Read first

| File                         | When                                                                 |
| ---------------------------- | -------------------------------------------------------------------- |
| [DESIGN.md](DESIGN.md)       | Before any change that affects how the site looks                    |
| [docs/SPEC.md](docs/SPEC.md) | Scope, content and SEO decisions                                     |
| `docs/private/PLAN.md`       | What to work on next, launch steps, open audit items (local only)    |
| `docs/private/BASELINE.md`   | Search data; check before changing URLs, titles or redirects (local) |

`docs/private/` is gitignored and exists only on Austin's machine. If it's
missing, ask; don't recreate it from memory.

## Commands

| Command                                         | What it does                                                                                        |
| ----------------------------------------------- | --------------------------------------------------------------------------------------------------- |
| `bun install`                                   | Install dependencies (Bun only; no npm/pnpm lockfiles)                                              |
| `bun run dev`                                   | Astro dev server, http://localhost:4321                                                             |
| `bun run build`                                 | Static build to `dist/`                                                                             |
| `bun run preview`                               | Build, then serve `dist/` with `wrangler dev` (applies `_redirects` and `_headers` like production) |
| `bun run check`                                 | Type-check Astro, TS and TSX files                                                                  |
| `bun run format`                                | Prettier (Astro + Tailwind class sorting)                                                           |
| `bun run test:redirects [url]`                  | Check redirects, status codes and headers; starts `wrangler dev` on `dist/` when no URL is given    |
| `bun run shot <url> <out.png> [w] [h] [--full]` | Screenshot a page in headless Chromium                                                              |
| `bun run deploy`                                | Manual build and deploy, for emergencies only (**ask Austin first**)                                |

Before calling a change done: `bun run check`, `bun run build`, and
`bun run test:redirects` if you touched routes, redirects, headers or config.
For visual changes, screenshot desktop (1440×900) and mobile (390×844).

## Layout of the code

- `src/content/`: all page copy, in Markdown (`intro.md`, `about.md`,
  `pursuits/*.md`). `src/data/site.ts`: title, meta description, social links.
- `src/layouts/BaseLayout.astro`: `<head>`, meta, structured data.
  `SplitLayout.astro`: the photo + content frame both pages use.
- `src/components/ui/`: shadcn components, generated by its CLI (excluded
  from Prettier).
- `public/_redirects`, `public/_headers`: Cloudflare redirect and header rules.
- `scripts/`: the redirect test and screenshot tools.

## Deploys

Cloudflare Workers Builds deploys `main` automatically. Every other branch gets
a Preview URL (posted on its pull request). Ship changes by branch → PR →
merge, not with `bun run deploy`.

## This repo is public

Never commit: account or zone IDs, DNS or email setup, analytics or Search
Console data, anyone's contact details, or photos with EXIF/GPS metadata.
Wrangler reads `CLOUDFLARE_ACCOUNT_ID` from a gitignored `.env`. Private notes
belong in `docs/private/`.

## Conventions

- **Copy belongs to Austin.** Don't write or rewrite page copy. You may fix
  plain typos, and should flag (not change) facts that contradict IMDb or his
  profiles. Placeholder
  files start with a `<!-- Placeholder ... -->` comment. Site copy uses no em
  dashes.
- **No client-side JavaScript.** React renders shadcn components at build time
  only; don't add `client:*` directives without asking. The build fails
  if any page loads a script.
- **URLs have no trailing slash** (`/about`). Pages build as files
  (`build.format: 'file'`), and `BaseLayout` derives canonical URLs from that.
  In `_redirects`, specific rules go first, splat rules after, and the
  trailing-slash rule stays last.
- **Styling** uses shadcn's semantic classes (`text-muted-foreground`,
  `text-primary`), never raw hex. Mustard (`primary`) is only for links, hover
  and focus. Details in DESIGN.md.
- **shadcn:** add components with `bunx --bun shadcn@latest add <name>`;
  import `cn` from `'cn'`.
- **Images** go through `astro:assets`. `ProfilePhoto.astro` is the profile
  photo only, not a general image component; new images use Astro's
  `<Image>`/`<Picture>` (or responsive images via `image.layout`). When
  preparing source photos, strip EXIF but keep the color profile
  (`magick in.jpg +profile '!icc,*' out.jpg`), never `-strip`.
- **TypeScript 6**, not 7: `astro check` doesn't support TS 7 yet.

## Ask Austin first

- Visible design changes: propose them, don't apply them.
- Deploying, pushing to `main`, or merging into `main`. Pushing your own
  `build/*` branch is fine.
- Any change in the Cloudflare dashboard or API. Reading is fine (Wrangler or
  the `cf` CLI, with `CLOUDFLARE_ACCOUNT_ID` from `.env`). Never touch the DNS
  records on the do-not-touch list in `docs/private/PLAN.md`.

## Git

Work on a `build/<topic>` branch and push it explicitly
(`git push -u origin build/<topic>`); a bare `git push` asks first. Commits are
signed; if signing fails, ask Austin rather than disabling signing.
